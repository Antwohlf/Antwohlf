# Hey, I’m Anthony

I’m a backend software engineer at Propio Language Services. Before that, I was an L5 Software Development Engineer at Amazon working on backend systems for an API platform handling more than 120 billion requests each month.

Most of my side projects start with something I would find useful and grow from there. I spend a lot of my free time building web apps, maintaining a small home lab, and trying practical uses for AI.

## Current projects

📄 **[Resume Revamped](https://resumerevamped.com)**

A resume builder with multiple themes, a live preview, AI-assisted feedback, and PDF export through Playwright.

🍕 **[A Pizza Michigan](https://www.apizzamichigan.com)**

A personal pizza spreadsheet that gradually became a searchable map and directory for more than 200,000 pizza and taco records.

🏗️ **[BuiltHere.city](https://builthere.city)**

A map and feed for following permits and development projects in Ann Arbor and Detroit.

🗺️ **[Map Data Aggregation and Enhancement Pipeline](https://github.com/Antwohlf/map-data-aggregation-enhancement-pipeline)**

The shared pipeline behind A Pizza Michigan, TacoBoutMichigan, and BuiltHere.city. It uses product-specific plugins and adapters for sources such as OpenStreetMap, Foursquare, Overture, official websites, and municipal ArcGIS feeds, with separate review and publication boundaries for each project.

🎬 **[Multi-Take Image Generation Pipeline](https://github.com/Antwohlf/multi-take-image-generation-pipeline)**

A CLI for generating, comparing, and approving consistent image sets across time, weather, and season. It grew out of the background system on my personal website.

🦉 **[DuoCalculator](https://www.duocalculator.com)**

A small Duolingo course planner with a weekly data pipeline covering more than 300 courses.

🏠 **Self-Hosted Home Lab**

A Linux server for the services and automation I run at home. It uses Docker, pooled storage, VPN-routed traffic, and remote access through a reverse proxy.
